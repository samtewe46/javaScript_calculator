# JavaScript Calculator

A responsive, browser-based calculator built using HTML, CSS, and vanilla JavaScript.

This project was created to practice frontend development fundamentals, DOM manipulation, event handling, and JavaScript state management.

## Features

- Addition, subtraction, multiplication, and division
- Decimal number support
- Chained arithmetic calculations
- Switching operators before entering the next number
- Clear button to reset calculator state
- Division-by-zero error handling
- CSS Grid-based calculator layout

## Technologies Used

- **HTML5** — Calculator structure and buttons
- **CSS3** — Layout, styling, and responsive design
- **JavaScript** — Calculator logic and user interactions
- **Git & GitHub** — Version control and source code hosting

## Getting Started

1. Clone this repository:
   `git clone https://github.com/samtewe46/javaScript_calculator.git`
2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or installation are required.

## How It Works

The calculator uses JavaScript functions to manage user input and arithmetic operations.

- `showNumber()` — Handles number input.
- `chooseOperator()` — Stores the selected arithmetic operator.
- `calculate()` — Performs calculations using a switch statement.
- `addDecimal()` — Handles decimal point input.
- `clearDisplay()` — Resets the calculator state.
